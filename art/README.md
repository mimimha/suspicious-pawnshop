# art (원본 마스터 아트)

여기 있는 파일은 **게임에 배포되지 않는다.** `public/` 밖이라 Vite 빌드에 포함되지 않는다.

- `items/` — 매입품 원본 (1254×1254). 게임은 `public/assets/items/`의 256px 축소본을 쓴다.
- `special-items/` — 특수 아이템 아이콘 원본 (약 1254×1254). 게임은
  `public/assets/ui/special-items/`의 256px 축소본을 쓴다.

게임에서 그리는 최대 크기가 190px여서, 원본을 그대로 쓰면 축소 계단이 심하게 보인다.
표시 크기를 키워야 하면 여기 원본에서 다시 축소본을 만든다.
