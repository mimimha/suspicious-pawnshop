# Task

## 목표

`docs/prd/step-07/prd-7-5-user-background-integration.md`와
`docs/prd/step-01/prd-1-2-customer-trade.md`에 따라 상단·좌측 UI를 제공 에셋으로
재조립하고 거래 버튼 흐름을 단순화하며, 플레이 배경을 클린 에셋으로 교체한다.

## 범위

- DAY·현금·신뢰도는 전용 프레임 에셋과 기준 이미지 정렬을 사용한다.
- 좌측 메뉴는 `시세 장부`·`메모`를 제거하고 `아이템`·`매입품` 두 항목만 표시한다.
- `매입 제안`은 현재 제안가를 즉시 제출한다.
- `흥정하기` 버튼을 제거하고 `거절한다`를 그 자리로 이동한다.
- 숫자 직접 입력, 100원 화살표, Enter 보조 단축키는 유지한다.
- UI가 미리 합성된 배경 대신 `public/assets/background-clean.png`를 사용한다.
- 첫 제안 전 하단의 `손님 제안가 그대로 또는 금액 수정 후 매입 제안` 안내 문구를 제거한다.
- 제안가 100원 증감 화살표의 기호와 클릭 영역을 확대한다.
- 좌측 메뉴 아래의 종료 화살표를 제거하고 화면 왼쪽 하단에 `장사 종료` 버튼을 배치한다.
- 장사 종료 버튼은 제안가 컨테이너와 같은 중심 높이와 108px 높이로 정렬한다.
- 자동 검증 후 사용자 플레이테스트 상태로 전환한다.
- 수동 종료·타이머 종료·마지막 DAY를 포함한 모든 영업 종료에서 셔터를 먼저 내리고,
  완전히 닫힌 뒤 후속 화면을 연다.
- 보유 아이템 팝업을 실제 매입품 이미지가 들어간 3×3 자주색·황동 진열장 UI로 교체한다.
