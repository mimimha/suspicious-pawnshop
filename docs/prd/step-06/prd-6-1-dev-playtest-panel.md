# PRD 6-1 — 개발용 통합 플레이테스트 패널

> 출처: 사용자 지시 및 기존 PRD 1-1~5-7 플레이테스트 항목
> 작성일: 2026-08-19

## 목표

STAGE 1~2 전체 기능을 기다림과 랜덤 반복 없이 검증할 수 있도록 개발 환경 전용 테스트 패널을 제공한다.

## 범위

- `import.meta.env.DEV`에서만 패널과 단축 기능을 생성한다.
- 패널 열기/닫기, STAGE 2 바로가기, 현금 지급, 모든 특수 아이템 지급, 재고 채우기, 가품 손님 호출, 다음 불만 제안의 공격/결렬 강제, DAY 즉시 종료를 제공한다.
- 강제 결과는 다음 조건을 만족하는 한 번의 판정에만 적용하고 즉시 해제한다.
- 기존 시스템의 공개 메서드와 정상 상태 전이를 사용하며 프로덕션 게임 규칙에는 영향을 주지 않는다.
- 패널은 현재 상태에서 실행할 수 없는 동작을 거부하고 안내 메시지를 표시한다.

## 완료 조건

1. 개발 서버에서 패널을 열고 닫을 수 있다.
2. STAGE 1 시작 화면에서 STAGE 2 DAY 1 판매창으로 바로 이동할 수 있다.
3. 현금·특수 아이템·재고를 즉시 준비할 수 있다.
4. 영업 중 가품 손님을 호출할 수 있다.
5. 다음 불만 제안의 공격 또는 결렬을 한 번만 강제할 수 있다.
6. DAY를 즉시 종료할 수 있다.
7. 프로덕션 빌드에는 패널이 표시되지 않는다.
8. 전체 테스트·타입 검사·빌드가 통과한다.

## 범위 밖

- 일반 플레이어용 치트 메뉴
- 세이브 파일 편집
- 아트·애니메이션·사운드 검증
