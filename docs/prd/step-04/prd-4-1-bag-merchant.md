## 목표

STAGE 마지막 DAY의 영업이 끝난 뒤 보따리 상인이 한 번 방문해, 플레이어가 가진 매입품을 일반 시세와 다른 제안가에 마지막으로 판매하거나 다음 STAGE까지 보유할 수 있게 한다. 상인 거래 종료 뒤에는 월세 정산으로 이어질 명확한 연결점을 만든다.

## 사용자에게 보이는 최소 플레이 흐름

```text
DAY 3 영업 종료
  → 샤따 내려감
  → 샤따가 반쯤 다시 올라감
  → 보따리 상인 방문
  → 매입 희망 물품과 제안가를 한 번에 제시
  → 보유 중인 일치 물품 판매 또는 보유
  → 상인 거래 종료
  → 샤따가 다시 내려감
  → 아이템 상점
  → 월세·STAGE 정산
```

## 구현 범위

### 1. BagMerchant 시스템

- Phaser에 의존하지 않는 `BagMerchant`가 이번 방문의 매입 제안 목록과 종료 여부를 소유한다.
- 제안은 STAGE 마지막 DAY 영업 종료 후 한 번만 생성한다.
- 각 제안은 물건 종류와 `기준가 × 상인 배율`로 계산한 고정 매입가를 가진다.
- 상인 배율은 기준가의 40~180% 범위에서 생성한다.
- 제안 생성 후에는 거래창을 닫을 때까지 가격이 바뀌지 않는다.
- 난수 공급자를 주입할 수 있어 제안 품목·가격 범위를 단위 테스트한다.

### 2. 제안 목록

- 상인은 방문 시작 시 플레이어가 실제로 보유한 매입품 종류에 대해서만 고정 제안가를 만든다.
- 한 페이지에는 최대 5종을 표시하며 5종보다 적으면 남는 슬롯은 아무 정보가 없는 빈 슬롯으로 유지한다.
- 보유 종류가 6종 이상이면 카드 목록 바깥의 좌우 화살표로 다음 제안 페이지를 이동하며,
  별도 페이지 번호는 표시하지 않는다.
- 사용자 승인 변경(2026-08-25): 다섯 카드 바깥을 다시 감싸는 목록용 대형 테두리는 제거하고
  배경에 인쇄된 개별 카드 프레임만 사용한다. 화살표는 배경 상자 없이 hover 시 색만 바뀐다.
- 사용자 승인 변경(2026-08-25): 선택한 카드의 강조선은 개별 카드 프레임 전체에 맞춘 금색으로
  표시하며, 보유 수량·물건명·가격 텍스트는 각 카드의 가로 중앙에 정렬한다.
- 같은 방문의 제안 목록에는 동일한 물건 종류가 중복되지 않는다.
- 플레이어가 제안 품목과 같은 종류의 물건을 보유하면 그 재고 인스턴스 하나를 판매할 수 있다.
- 같은 종류를 여러 개 보유한 경우 한 번 판매할 때 가장 먼저 들어온 인스턴스 하나를 판매한다. 해당 제안은 유지되어 남은 동일 물건도 같은 가격에 추가 판매할 수 있다.

### 3. 판매 처리

- 제안 칸을 클릭하면 즉시 판매하지 않고 해당 물건을 선택한다.
- 선택한 재고의 내 매입가와 상인 제안가를 하단 상세 영역에 표시한다. 사용자 승인 변경
  (2026-08-25): 판매 전 예상 손익 줄은 표시하지 않으며, 판매 완료 팝업의 실현 손익은 유지한다.
- 별도의 `선택 물건 판매` 버튼을 눌러야 흥정 없이 표시된 제안가로 판매한다.
- 판매 시 일치하는 재고 인스턴스 하나를 제거하고 현금을 제안가만큼 증가시킨다.
- 판매 내역은 당일 장부에 `보따리 상인 판매`로 별도 기록한다.
- 판매 완료 피드백에는 매입가, 상인 판매가, 실현 손익, 보유 기간을 표시하며 거래의 좋고
  나쁨을 판정하는 문구는 사용하지 않는다.
- 사용자 승인 변경(2026-08-24): 판매 완료 정보는 상세 영역의 일반 문자열로 표시하지 않고
  기존 목재·황동 판매 완료 결과와 같은 중앙 팝업으로 표시한다. 확인 전에는 상인 화면 입력을 막는다.
- 판매로 마지막 동일 품목이 사라지면 해당 제안은 목록에서 즉시 빠지고 남은 슬롯은 빈 상태가 된다.
- 판매하지 않은 재고에는 변화가 없다.

### 4. DAY 3 종료 연결

- DAY 1과 DAY 2는 기존 명세서와 다음 DAY 흐름을 유지한다.
- DAY 3 영업 종료 시 수동 종료·타이머 종료 모두 셔터 하강을 먼저 재생한다.
- 셔터가 완전히 내려온 뒤 1초간 닫힌 상태를 유지하고 셔터를 반쯤 다시 올린다. 반개방 전환이 끝나면 보따리 상인 화면을 연다.
- `상인 거래 종료`를 누르면 셔터가 상인 화면 위로 다시 완전히 내려온다.
- 셔터 하강이 끝난 뒤 판매 기회를 닫고 아이템 상점을 연다. 아이템 상점을 닫은 뒤에만 월세·STAGE 정산으로 이동한다.
- 이번 PRD에서는 월세를 차감하거나 성공·GAME OVER를 판정하지 않는다.
- 상인 화면을 닫은 뒤 같은 STAGE에서 다시 열 수 없다.
- 배경 우측 상단 X 버튼은 `상인 거래 종료` 버튼과 동일하게 방문을 종료하고 다음 단계로 진행한다.
- 상세 영역의 물품명·진품 여부·매입가·제안가는 배경에 인쇄된 라벨과 겹치지 않도록 각각 고정된 행에 표시한다.
- 사용자 승인 변경(2026-08-24): 상세 수치는 배경의 `매입가` 라벨 오른쪽에 매입가 숫자,
  다음 줄 `제안가` 라벨 오른쪽에 제안가 숫자가 오도록 정렬한다.

- 보따리 상인과의 흥정

- 특수 아이템 구매와 판매

## 시스템 책임

- **BagMerchant**: 제안 생성, 제안 가격, 방문 종료 상태.
- **Inventory**: 일치 물건 조회와 특정 인스턴스 제거.
- **GameState**: 상인 판매 수익 반영과 STAGE/DAY 상태.
- **DailyLedger**: 일반 판매와 구분되는 상인 판매 기록.
- **DayScene**: DAY 3 종료 감지, 상인 UI와 시스템 호출 조정.

## 완료 조건

1. DAY 1·2 종료 흐름은 기존대로 유지된다.
2. DAY 3 영업 종료 후 셔터가 완전히 내려왔다가 반쯤 올라간 뒤 보따리 상인 화면이 정확히 한 번 열린다.
3. 서로 다른 물건 5종과 각 제안가가 한 화면에 표시된다.
4. 모든 제안가는 해당 물건 기준가의 40~180% 범위다.
5. 제안은 방문 중 고정되며 새로고침되지 않는다.
6. 보유한 일치 물건만 판매할 수 있다.
7. 판매 시 해당 재고 하나만 제거되고 현금과 장부가 정확히 증가한다.
8. 동일 종류 재고를 여러 개 보유하면 같은 제안가로 하나씩 판매할 수 있다.
9. 거래 종료 시 미판매 재고를 유지하고 셔터 재하강 뒤 아이템 상점으로 이동한다.
10. 상인 거래 종료 후 화면을 다시 열 수 없다.
11. 기존 전체 테스트와 `npm run typecheck`, `npm run build`, `npm test`가 통과한다.

## 승인 시 확정되는 사항

1. 상인은 중복 없는 물건 5종을 한 번에 제시한다.
2. 제안가는 기준가의 40~180%에서 정하고 100원 단위로 반올림한다.
3. 같은 종류의 재고는 같은 제안가로 여러 개 판매할 수 있다.
4. 상인 거래 종료는 되돌릴 수 없으며 다음 PRD의 월세 정산으로 이어진다.
