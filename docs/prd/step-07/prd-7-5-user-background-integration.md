## 사용자 제공 버튼 에셋

- 하단 거래 행동은 `매입 제안`과 `거절하기` 두 버튼만 사용한다.
- 코드로 만든 배경색과 텍스트 버튼을 에셋 위에 중복 표시하지 않는다.
- 버튼보다 한 칸 더 왼쪽의 긴 정보 칸 오른쪽 끝에 제안가 숫자와 100원 증감 화살표를
  포함한 입력 패널을 둔다.
- 제안가 패널의 주 정보 행은 `제안가` 라벨, 금액, 하향·상향 화살표를 같은 세로 중심선에
  정렬한다. 화살표는 프레임 안쪽 안전 여백을 확보한 동일 크기 버튼으로 표시하고, 손님 최초
  제시가는 주 정보 행 아래에서 패널 가로 중앙에 배치한다.
- `매입 제안`은 손님의 최초 희망가로 초기화된 현재 입력값을 즉시 제출한다. 플레이어가 값을
  바꾸지 않으면 손님 희망가 그대로 제안하고, 숫자를 덮어쓰거나 100원 화살표로 조정하면
  바뀐 금액으로 제안한다.
- 제안가 패널 자체가 직접 입력을 활성화하고, `매입 제안`은 현재 금액 제출,
  `거절하기`는 거래 포기를 담당한다. 별도 `흥정하기` 버튼은 표시하지 않는다.
- hover와 클릭 영역은 이미지 전체를 사용하며 기존 키보드·화살표 입력은 유지한다.

  않으며, 거래 중 읽기 쉬운 크기로 제안가 보조 문구보다 크게 표시한다.

  유지해 표시하며 가로·세로를 서로 다른 배율로 늘이지 않는다.
- 상단 돋보기 문양과 제목 사이에 충분한 패딩을 두고, 제목과 본문을 기존보다 아래로 내려
  장식과 문구가 붙어 보이지 않게 한다.
- 확인 버튼은 원본 비율을 유지하고 프레임 하단 금색 라인과 겹치지 않도록 기존보다 위에 배치한다.

## 완료 조건

- 사용자가 제공한 이미지가 실제 게임 배경으로 표시된다.
- 기존 코드로 만든 큰 좌우 정보 패널이 배경을 가리지 않는다.
- 동적 DAY, STAGE, 시간, 현금, 손님, 물건과 조작부가 원본 프레임에 맞는다.
- DAY·현금의 문구 형식, 색상과 글꼴 분위기가 배경에 그려진 예시 HUD와 자연스럽게 이어진다.
- 영업 중 신뢰도 라벨·게이지·퍼센트가 배경 예시의 구성과 같은 위치 관계로 표시된다.
- 상단 동적 HUD가 지나치게 깨끗한 디지털 텍스트가 아니라 배경과 같은 낡은 인쇄물처럼 보인다.
- 상단 HUD 3개 프레임과 좌측 `아이템`·`매입품` 메뉴가 사용자 제공 에셋으로 조립된다.
- UI가 미리 합성되지 않은 클린 배경 위에 동적 UI만 한 번 표시되어 중복 흔적이 없다.
- 하단 긴 정보 칸의 제안가 입력과 오른쪽 이미지 버튼 2종이 각 칸에 맞고 정상 동작한다.
- 하단에서 신뢰도를 제거한 공간만큼 제안가 숫자를 확대해 한눈에 읽을 수 있다.
- 테스트, 타입 검사, 빌드가 통과한다.
- 최초 게임 시작과 일반 DAY 전환 모두 같은 셔터 에셋의 상승·하강 연출을 사용한다.
- 플레이 HUD와 모든 행동 버튼이 원본 비율을 유지하고, 같은 계열의 프레임 두께·모서리·금속
  장식을 사용한다.
- 하단 조작부의 황동색 면적이 프레임 전체를 지배하지 않고 배경의 어두운 목재·철제 분위기와
  자연스럽게 이어진다.

## 사용자 승인 변경 — 좌측 메뉴 버튼 크기·배경·화풍 통일

- 시세 장부·아이템·매입품 버튼은 모두 동일한 90×90 캔버스와 약 84×84의 실제 프레임 점유율을 사용한다.
- 세 에셋의 버튼 바깥 캔버스는 투명하게 처리해 뒤의 목재 HUD 배경이 그대로 보이게 한다.
- 회색 외곽 프레임을 제거하고, 매입 제안 버튼을 기준으로 짙은 녹색 내부 면과 절제된 황동 이중 테두리를 적용한다.
- 책·돋보기·가방 아이콘은 유지하고 동일한 시각 크기와 중앙 정렬로 맞춘다.

## 사용자 승인 변경 — 상단 소지금액·시간 정렬 및 방문자 글자 축소

- 소지금액과 타이머 텍스트의 중심 y를 각 카드 중심인 40px로 통일한다.
- 방문자 수의 기본 글자 크기는 기존 29px의 60%인 반올림 17px로 줄인다.
- 방문자 문구가 길어질 때는 17px을 상한으로 기존 안전 영역 자동 축소를 유지한다.
