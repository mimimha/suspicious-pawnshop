# PRD 7-3 — 사용자 제공 매입품 이미지와 등장 목록 적용

- 상태: 사용자 승인 변경 · 아트 적용
- 스냅샷: 2026-08-19
- 출처: Notion `매입품 UI`, `물건·감정 규칙`

## 목표

사용자가 제공한 개별 매입품 이미지 9종을 실제 등장 물건과 1:1로 연결하고, 거래 물건과
재고 상세에 해당 이미지를 표시한다.

## 최종 에셋 사용 규칙

- 매입품은 완성 손님 에셋의 일러스트 화풍과 톤을 시각 기준으로 삼는다.
- 사용자 승인된 v3 화풍 9종을 `public/assets/items/`의 실제 런타임 에셋으로 사용한다.
- 파일 이름은 코드의 물건 ID에 맞춘 짧은 영문 이름으로 통일한다.
- `final/`에는 실제 게임에서 사용하는 9개 PNG만 남기고, 교체 전 원본·v2·합성 시트와
  중복 v3 작업 파일은 제거한다.
- 한 장짜리 합성 이미지 crop과 대응 이미지가 없는 임시 물건은 더 이상 사용하지 않는다.

## 등장 물건 목록

### STAGE 1부터 등장

- 빈티지 카메라
- 회중시계
- 구형 동전 세트
- 앤티크 라이터
- 오래된 라디오
- 앤티크 안경

### STAGE 2부터 추가 등장

- 인장 반지
- 고서적
- 만년필

개별 가격과 희귀도는 기존 시드의 대응 슬롯을 유지하는 현재 테스트값이다.

## 화면 적용

- 손님 거래 화면: 현재 손님이 제시한 물건을 오른쪽에 표시한다.
- 재고 팝업: 보유 물건을 선택했을 때 상세 정보 옆에 표시한다.
- 모든 등장 물건은 이름과 동일한 개별 이미지를 사용한다.
- 매입품 원본 PNG와 화풍은 변경하지 않고, 공통 표시 크기에 물건별 상대 배율을 적용한다.
  현실 크기를 완전히 재현해 작은 물건의 가독성을 잃지 않는 범위에서 라디오·고서적은 크게,
  카메라는 기준 크기, 안경·동전·만년필은 중간, 회중시계·라이터는 작게, 인장 반지는 가장
  작게 표시한다. 배율은 사용자 승인 변경이며 현재 테스트값이다.

## 완료 조건

- 등장 목록이 위 9종으로만 구성된다.
- 9종 모두 거래 화면과 재고 상세에서 이름에 맞는 이미지가 표시된다.
- 이전 합성 이미지 crop과 임시 물건 이름이 실제 등장 목록에 남지 않는다.
- 투명 배경과 원본 비율을 유지하며 UI 영역 안에 들어온다.
- 테스트, 타입 검사, 프로덕션 빌드가 통과한다.

## 아트 스타일 조정 테스트

- 상태: 사용자 승인 변경 · v3 화풍 최종 적용
- 기준 에셋: `public/assets/customers/wolf.png`
- 확정 스타일 기준: `public/assets/items/vintage-camera.png`
- 9종 모두 v3 결과물을 최종 에셋으로 사용하며 별도의 `-v3` 접미사는 런타임 파일명에 남기지 않는다.
- 굵고 자연스러운 외곽선, 넓은 색면, 2~3단계 셀 명암, 절제된 황동색과 소수의
  마모 흔적을 공통 규칙으로 적용한다.
