# PRD 7-2 — 손님 성향별 캐릭터 아트

- 상태: 사용자 요청에 따른 아트 적용
- 스냅샷: 2026-08-19
- 기반 기획: Notion `손님` 페이지의 현재 개별 이미지와 STAGE 2 손님 유형·신뢰도 시스템

## 목표

거래 중인 손님의 성향을 글뿐 아니라 표정과 자세로도 직관적으로 전달한다.

## 캐릭터 구성

- 정직형: 노션 원본 부엉이 손님
- 일반형: 노션 원본 너구리 손님
- 의심형: 노션 원본 두루미 손님
- 사기형: 노션 원본 뱀 손님

Notion의 `old` 토글 안에 있는 폐기 시안은 사용하지 않는다. 현재 영역의 개별 손님 원본만 사용한다.

## 화면 규칙

- 손님은 노션 원본의 비율을 유지해 표시한다.
- 카운터 뒤 화면 왼쪽에 표시하고 거래 정보는 오른쪽으로 옮긴다.
- 현재 거래가 있을 때만 표시하며 손님 유형이 바뀌면 즉시 해당 이미지로 교체한다.
- 팝업과 셔터는 기존 depth 규칙에 따라 손님 이미지보다 앞에 표시한다.

## 완료 조건

- 네 성향 모두 서로 다른 이미지로 표시된다.
- 손님이 없거나 영업이 끝나면 이미지가 숨겨진다.
- 기존 흥정 입력과 텍스트가 캐릭터에 가려지지 않는다.
- 테스트, 타입 검사, 프로덕션 빌드가 통과한다.
