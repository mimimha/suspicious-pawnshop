# PRD 7-1 — 전당포 공통 배경과 UI 톤

- 상태: 사용자 요청에 따른 아트 1차 적용
- 스냅샷: 2026-08-19

## 목표

기존 기능과 배치를 유지하면서 전당포 카운터 중심의 분위기와 일관된 UI 색감을 만든다.
텍스트 가독성과 플레이 정보 전달이 장식보다 우선이다.

## 아트 방향

- 오래된 동네 전당포를 정면에서 바라보는 16:9 카운터 시점
- 짙은 목재·차콜 그림자·낡은 황동·절제된 호박색 조명
- 화면 중앙은 손님 정보와 흥정 UI가 읽히도록 어둡고 차분하게 비운다.
- 상단 상태판과 중앙 거래판은 반투명한 짙은 패널과 얇은 황동 테두리를 사용한다.
- 본문은 따뜻한 미색, 보조 정보는 회갈색, 상호작용 요소는 호박색을 사용한다.
- 팝업의 영수증·셔터·3×3 재고 구조는 기존 기획을 유지한다.

## 에셋 규칙

- 이전에 생성한 사진 시안은 참조하거나 재사용하지 않는다.
- 이번 배경은 텍스트·인물·상표가 없는 새 원본으로 제작한다.
- 단순 패널과 버튼은 Phaser 도형과 텍스트로 구현해 해상도와 상태 변화에 대응한다.
- 손님, 물건, 특수 아이템의 최종 일러스트는 다음 아트 작업에서 개별 제작한다.

## 적용 범위

1. 공통 전당포 실내 배경 1종
2. 전체 화면 명암 오버레이
3. 상단 상태판과 중앙 거래판
4. 본문·보조 정보·버튼의 공통 색상 정리

## 완료 조건

- 1280×720에서 배경이 왜곡이나 빈 공간 없이 표시된다.
- 기존 거래 조작과 팝업 동작이 변하지 않는다.
- 중앙 텍스트가 배경 디테일과 겹쳐도 읽을 수 있다.
- 타입 검사, 테스트, 프로덕션 빌드가 통과한다.
