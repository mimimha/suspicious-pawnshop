# PRD 7-4 — 노션 시안 기반 플레이 화면 재구성

- 상태: 사용자 피드백 반영
- 스냅샷: 2026-08-19
- 출처: Notion `배경`, `손님`, `매입품 UI`, `아이템 UI`

## 문제

기존 1차 화면은 노션 이미지를 개별 배경·캐릭터·물건으로만 사용해, 노션 시안이 가진 전체 UI 문법을 반영하지 못했다.

## 시안에서 가져올 화면 문법

- 사용자 승인 변경(2026-08-23): 플레이 화면 공통 UI는
  `docs/mockups/play-screen-redesign-concept-v4-storybook.png`의 판화·동화책형 시각 문법을
  기준으로 재구성한다. 굵고 단순한 외곽선, 평면적인 종이 질감, 검정·짙은 자주색 바탕,
  탁한 황토색 테두리와 미색 글자를 공통으로 사용하며 사실적인 금속 반사와 입체 재질 표현은
  줄인다.
- 실제 게임용 UI 이미지에는 DAY, 현금, 신뢰도, 방문자, 시간, 제안가, 대사, 버튼 이름 등
  런타임에 바뀌거나 현지화될 수 있는 텍스트·숫자를 포함하지 않는다. 프레임, 빈 게이지 트랙,
  버튼 바탕, 아이콘을 각각 투명 PNG로 분리하고 텍스트·수치·게이지 채움은 Phaser가 위에
  동적으로 렌더링한다.
- 신뢰도 UI는 빈 패널과 빈 트랙만 이미지 에셋으로 제공하고 현재 수치와 보라색 채움 폭은
  런타임 상태를 기준으로 계산한다. 제안가·현금·방문자·시간도 같은 원칙을 적용한다.
- 사용자 승인 변경(2026-08-23, 후속): 실제 플레이 화면의 최종 분리 기준은 사용자 제공
  `bg.png` 목업으로 교체한다. 목업의 어두운 목재 전당포, 중앙 보라색 거래 매트, 우측
  분홍색 `전당포` 네온과 검정·황동 HUD, 녹색·보라색·적갈색 행동 버튼 구성을 기준으로
  배경과 UI를 독립 레이어로 제작한다. 앞서 승인한 판화·동화책형 시안은 탐색 시안으로
  보존하되 실제 분리 에셋 기준으로 사용하지 않는다.
- 원 배경 레이어에는 HUD, 좌측 메뉴, 하단 패널과 버튼, 동적 텍스트·수치·게이지 채움을
  포함하지 않는다. 전당포 실내, 조명, 선반, 네온 간판, 카운터와 보라색 매트만 남긴다.

- 화면 최상단을 DAY·STAGE·시간·현금·월세가 한 줄로 이어진 황동 프레임 상태바로 구성한다.
- 손님 정보는 왼쪽 카드, 손님 캐릭터는 중앙 무대, 거래 정보와 물건은 오른쪽 카드로 분리한다.
- 흥정 반응은 말풍선형 패널, 행동 버튼은 하단의 큰 황동 프레임 버튼으로 구성한다.
- 검은 목재 바탕, 자주색 벨벳 포인트, 낡은 황동 선, 따뜻한 미색 글자를 공통 사용한다.
- 기능 버튼은 화면 가장자리로 분리해 거래 정보의 시각적 위계를 방해하지 않게 한다.
- 모든 손님 일러스트는 같은 `y=289` 기준 좌표에 배치해 이미지 하단이 테이블 뒤에 자연스럽게
  걸리게 한다. 렌더링 순서는 `배경 < 손님 < 매입품`으로 유지해 손님은 배경 앞에, 제시
  물건은 손님 앞에 보이게 한다.
- 손님 PNG에는 공통 사각형 크롭을 적용하지 않고 원본 이미지 전체 영역을 표시한다.
- 플레이 화면 시각 정돈 테스트값으로 손님 크기는 `0.36`, 중심은 `x=520, y=309`로 두어
  테이블 뒤 정렬을 유지하면서 중앙 여백을 확보한다. 제시 물건 최대 크기는 150px로 줄인다.
- 사용자 승인 변경(2026-08-23): 제시 물건은 이미지 캔버스의 중심 좌표가 아니라 실제로 보이는
  물건의 하단을 탁자 위 공통 기준선에 맞춘다. 이미지별 투명 여백 차이는 세로 위치 보정값으로
  흡수해 카메라·라디오처럼 여백과 크기가 다른 물건도 같은 높이에 놓인 것처럼 표시한다.
- 손님 말풍선은 사용자 승인 변경에 따라 `public/assets/ui/animal-speech-bubble-v2.png`를
  원본 비율 그대로 `360×203px`로
  표시하고 따뜻한 미색 글자를 프레임 안쪽에 배치해 전체 UI 문법과 통일한다.
- 방문자와 타이머 카드는 `y=40`, 높이 58px로 맞춰 현금·신뢰도 카드와 같은 중심선에 정렬한다.
- 마우스 포인터는 브라우저 기본 동작을 따른다. 일반 영역은 기본 화살표, 클릭 가능한 UI는
  손 모양을 사용해 요소별 상호작용 가능 여부를 구분한다.
- 플레이 화면의 모든 동적 한글·숫자 UI는 로컬 포함한 `Gowun Batang` 한 가지 서체로
  통일한다. 일반 대사·설명은 400 굵기, DAY·금액·타이틀·핵심 행동은 700 굵기를 사용해
  서체를 섞지 않고 정보 위계를 만든다.
- 사용자 승인 변경(2026-08-25): 거래 기록·아이템·매입품 도구창의 제목은 `거래 기록`의
  런타임 제목 설정(`UI_DISPLAY_FONT`, 굵게, 금색, 최종 32px)을 공통으로 사용한다.
- 사용자 승인 변경(2026-08-25): 플레이 HUD의 `DAY`·장사 일차·현금·신뢰도·
  방문자·타이머는 제안가 금액과 같은 `UI_DISPLAY_FONT`·700 굵기·황동색·29px를 기본으로
  맞춘다. 카드별 안전 폭·높이를 넘는 문구만 컨테이너 안에 들어갈 때까지 자동 축소한다.
- 사용자 승인 변경(2026-08-25): 신뢰도 카드는 영업 중 신뢰도만 표시하며, 장사 종료 이후
  `STAGE N · DAY N 영업 종료` 같은 상태 문구로 대체하지 않고 비워 둔다.
  하단 `매입 제안`, `거절한다`는 사용자 제공 개별 PNG 버튼을 유지하고 `장사 종료`는 기존
  검정·황동 프레임을 사용한다.

## 적용 범위

1. 상단 전체 상태바
2. 왼쪽 손님 정보 카드
3. 중앙 캐릭터 무대
4. 오른쪽 물건·흥정 카드
5. 하단 흥정 조작부
6. `아이템`·`매입품` 두 도구 메뉴의 좌측 세로 배치와 화면 왼쪽 하단의 독립 `장사 종료` 버튼.
   종료 버튼은 제안가 컨테이너와 같은 중심선을 사용한다. 제안가 컨테이너는 전용
   `dialogue-frame.png`를 `510×125px`로 표시한다.
7. 왼쪽 `아이템` 메뉴를 누르면 사용자 제공 `items (1).png`를 비율 유지한 소형 도구창으로
   표시한다. 도구창은 플레이 화면을 어둡게 하지 않고 영업 시간과 거래 입력을 멈추지 않는다.
   튜토리얼 중에는 좌측 메뉴 바로 옆의 고정 위치에 표시하고, 튜토리얼 종료 후에는 제목 영역을
   끌어 화면 안에서 옮길 수 있다. 창 위에 별도의 상시 드래그 안내 문구는 표시하지 않는다.
   `매입품` 창과 동시에 열 수 있다. 배경에 포함된 2×2 아이템 그림과 프레임 위에 감정 아이템·시세 확인 아이템·
   장사 시간 증량·방어 아이템의 이름과 현재 보유 수량을 동적으로 표시한다. 닫기 버튼과
   감정 아이템 사용 조건·동작은 기존 규칙을 유지한다.
   각 카드에 마우스를 올리면 검정 목재·어두운 자주색 안감·얇은 황동 테두리·제목 구분선을
   사용한 이미지형 툴팁으로 아이템 이름과 용도만 표시하고 보유 수량은 카드의 수량 칸에서만
   확인한다. 사용자 승인 변경(2026-08-24): 네 아이템 상세 툴팁의 제목은 현재 위치보다
   5px 아래에 표시하고 본문과 프레임 위치는 유지한다. 감정·
   시간 증량·방어 카드는 조건을 만족할 때 카드 클릭으로 직접 사용한다.
   툴팁은 대상 카드의 반대편에 배치하고, 왼쪽 카드에는 왼쪽 꼬리, 오른쪽 카드에는 오른쪽
   꼬리가 포함된 별도 프레임 이미지를 사용해 꼬리 끝이 해당 카드 가장자리를 가리키게 한다.
   아이템 순서는 구매 상점과
   동일하게 위쪽 `시세 확인·시간 증량`, 아래쪽 `감정·방어`로 통일한다.
   카드 이름·수량·툴팁 제목·설명은 최종 축소 후에도 매입품 창의 보유 슬롯처럼 읽을 수 있는
   명도와 내부 해상도로 렌더링한다.
8. `매입품` 메뉴는 소형 비모달 도구창으로 표시하고 3×3 재고 진열창은 마우스 오버 상세만
   제공한다. 슬롯 선택·보라색 선택 강조·위치 교환 입력은 사용하지 않는다. 배경 암전과 영업 시간 정지를 적용하지 않으며 튜토리얼 중에는 좌측 메뉴 옆에
   고정하고, 튜토리얼 종료 후에는 제목 영역을 끌어 옮길 수 있다. `아이템` 창과 동시에 열 수 있다.
- 사용자 승인 변경(2026-08-25): 매입품 팝업 제목의 가방 단독 아이콘은 기존 표시 크기의
  90%로 축소하고 최종 화면 기준 3px 왼쪽으로 이동한다. 제목 텍스트와 다른 요소는 유지한다.
   사용자 승인 변경(2026-08-23): 두 도구창은 원본 컨테이너를 통째로 축소하지 않고 좌표·프레임·
   아이콘을 68% 최종 표시 크기로 환산한다. 글자는 최종 폰트 크기와 4배 내부 해상도로 직접
   렌더링한다. 매입품 이미지는 256px 전용 썸네일을 사용해 작은 표시 크기에서도 윤곽이 뭉개지는
   현상을 줄인다. 상세 본문과 진품 여부 줄도 카드명·보유 슬롯과 같은 명도·굵기·해상도로 표시하며,
   두 창의 기본 위치는 서로 겹치지 않게 좌우로 나눈다.
9. 플레이 화면은 브라우저의 가용 너비·높이에 맞춰 16:9 비율로 함께 확대·축소한다.
   `아이템` 팝업의 2×2 카드, `매입품` 팝업의 3×3 슬롯, 물건 이미지·텍스트·클릭 영역도
   동일한 비율로 반응하며 내부 배치와 기준 해상도 좌표는 유지한다. 화면 비율이 16:9와
   다를 때는 잘라내거나 늘이지 않고 남는 영역을 여백으로 둔다. 모바일 브라우저 주소창처럼
   가용 높이가 바뀌는 경우에도 현재 뷰포트 높이를 다시 반영한다.
   상단 DAY·현금·신뢰도·방문자·시계 컨테이너는 동일한 상단 기준선과 컨테이너 사이 간격을 사용한다.
10. 판화·동화책형 플레이 HUD의 실제 적용 에셋은 재사용 가능한 최소 단위로 분리한다.
    공통 상태 카드, 신뢰도 카드와 빈 트랙, 좌측 도구 버튼, 빈 대사 패널, 제안가 패널,
    증감 버튼, 장사 종료 버튼, 매입·거절 버튼 및 각 기능 아이콘을 서로 독립적으로 교체할 수
    있어야 한다.
11. 사용자 제공 `bg.png` 기준 분리 에셋은 DAY 카드, 현금 카드, 신뢰도 카드와 빈 트랙,
    좌측 메뉴 공통 버튼, 좌측 접기 버튼, 하단 거래 정보 패널, 매입 제안·흥정하기·거절
    버튼 바탕, 기능 아이콘으로 구성한다. 버튼 문구와 상태 수치는 이미지에 포함하지 않는다.

13. 사용자 승인 변경(2026-08-25): 기존 CC0 `Medieval: Market Day` 배경음악은 사용자
    피드백에 따라 런타임에서 제거하고 교체 음원이 정해질 때까지 BGM 없이 효과음만 사용한다.
    기존 파일과 출처 기록은 후보 자료로 보존한다. 사용자 승인 변경(2026-08-25)에 따라
    매입 성공 동전음·거래 거절음은 사용하지 않는다. 사용자 승인 변경(2026-08-25)에 따라
    공통 버튼 클릭음은 Pixabay `Button click vintage sound FX`의 단발 클릭으로 교체하며,
    물리 입력 한 번에 한 번만 재생한다. 셔터 하강음은 상승음과
    분리해 금속 슬랫이 연속으로 부딪히는 덜컹임과 닫히는 순간의 낮은 충돌음을 표현한다.
    셔터 상승·하강은 사용자 지정 Pixabay `metal shutter` 현장 녹음에서 상승은 원본 2~3.6초,
    하강은 원본 5초 이후의 선행 저음량 구간을 제거한 5.58~8.08초를 원래 속도로 사용한다.
    하강음은 셔터 이동 시작과 동시에 재생하고 마지막 0.55초를 페이드아웃한다. 하강 화면 이동도
    1.5초로 진행하고, 효과음의 남은 약 1초는 닫힌 뒤 잔향으로 이어진다. 상승음은 재생 1초부터 0.6초 동안

## 완료 조건

- 노션 배경 시안과 같은 정보 위계가 1280×720 플레이 화면에서 보인다.
- 손님, 물건, 거래 텍스트와 버튼이 서로 겹치지 않는다.
- 장사 종료 버튼과 제안가 컨테이너가 같은 중심선에 정렬된다.
- 특수 아이템 팝업의 2×2 카드와 수량 표시가 서로 겹치지 않고 닫기 버튼으로 복귀할 수 있다.
- 매입품 팝업에서 3×3 매입품 이미지와 선택 상세 정보가 서로 겹치지 않는다.
- 매입품 상세 정보에는 시세 정보·진품 여부를 표시하고 예상 손익은 표시하지 않는다.
- 사용자 승인 변경(2026-08-26): 예상 판매가 줄도 제거했다. 기준가에서 계산된 값이라
  물건의 값을 알려 주는 것과 같기 때문이다(PRD 1-3 참고).
- 감정 도구를 사용한 매입품은 상세 정보에 `진품` 또는 `가품`을 표시하며 `미확인`으로 되돌아가지 않는다.
- 아이템·매입품 창을 열어 둔 동안 영업 시간과 손님 진행, 거래 조작이 계속된다.
- 두 도구창은 튜토리얼 중 정해진 위치에 표시되고, 종료 후 제목 영역 드래그로 화면 안에서 이동한다.
- 창 크기를 바꿔도 전체 캔버스와 아이템·매입품 팝업이 16:9 비율로 화면 안에 유지된다.
- 테스트, 타입 검사, 프로덕션 빌드가 통과한다.
- 선택한 미스터리 BGM이 게임 시작 후 낮은 음량으로 재생되며, 반복 경계에서 4초
  크로스페이드되어 갑자기 끊기지 않는다. 처음부터 다시 시작할 때는 페이드아웃한 뒤 타이틀로
  돌아간다. 동전·거절 효과음은 들리지 않으며 셔터·손님·명세서·타이핑 효과음을 가리지 않는다.
- 모든 인터랙티브 버튼은 한 번 누를 때 빈티지 클릭음이 한 번만 들린다.
- 셔터 하강음에서 연속 금속 마찰·슬랫 충돌과 마지막 닫힘 충격을 구분해서 들을 수 있다.
- 각 손님의 등장 디졸브가 시작될 때 벨이 한 번만 들리고 BGM과 대사를 가리지 않는다.

- DAY 1→2와 DAY 2→3에서 닫힌 셔터 위 `DAY`는 고정되고 숫자만 자연스럽게 교체된 뒤 판매 화면이 나타난다.
