# PRD 3-2 — STAGE 1 DAY 1 거래 튜토리얼

> 출처: 사용자 승인 변경 (2026-08-23)
> 관련 PRD: 1-2 고객 거래, 3-1 손님 큐, 5-2 감정권, 5-5 공격·병원비

## 목표

새 게임의 STAGE 1 DAY 1 첫 두 손님을 단계별 튜토리얼로 구성해 단서 관찰, 감정, 가격
조정, 매입, 과도한 흥정의 위험을 직접 클릭하며 익히게 한다. 튜토리얼을 완료하면 연습 결과를
초기화한 뒤 실제 영업 손님 다섯 명을 별도로 진행한다.

## 시나리오

1. 첫 손님은 정직형·진품 라디오를 9,000원에 제시한다.
   셔터가 완전히 열린 뒤에는 기본 HUD만 있는 빈 매장을 먼저 보여 준다. 첫 손님이 디졸브로
   등장하고 첫 대사를 시작한 뒤에만 1번 튜토리얼 오버레이와 설명창을 표시한다.
2. 단서 영역을 확인한 뒤 아이템 창에서 감정 아이템을 사용한다.
   아이템 사용 안내에는 아이템·매입품 창의 제목 부분을 끌어 옮길 수 있지만, 튜토리얼 중에는
   강조 위치를 유지하기 위해 고정되고 튜토리얼 종료 후부터 이동할 수 있음을 함께 설명한다.
3. 플레이어가 손님의 최초 제시가인 9,000원 이하의 양의 금액을 직접 입력·제안한다.
   8,000원 이상이면 바로 거래가 성사되고, 8,000원 미만이면 `조금만 더`라는 반응을 확인한다.
   첫 가격 입력 안내에서는 매입가가 낮을수록 이후 판매 이익의 여지가 커지지만 손님의 반응과
   거래 위험도 함께 고려해야 한다는 원칙을 설명한다. 이 단계에서 `Enter`로 제안하게 하고,
   튜토리얼 이후에는 금액 입력 후 `매입 제안` 버튼을 눌러도 제출할 수 있음을 먼저 안내한다.
4. 재협상 반응이 나온 경우 8,000원 이상을 직접 입력·재제안해 첫 매입을 성공시킨다.
   같은 손님과 흥정하는 동안에는 직전 제안가를 입력창에 유지하고, 그 금액을 기준으로 수정한다.
   7번 안내에서는 `8,000원 이상 입력 → Enter` 순서만 직접 안내한다.
   8,000원 미만이면 `손님이 받아들일 수 있는 최소 금액은 8,000원입니다. 8,000원 이상으로
   다시 제안해 주세요.`를, 보유 현금을 초과하면 `보유 현금을 초과했습니다. 보유 현금 이하의
   금액으로 다시 제안해 주세요.`를 안내창에 빨간색으로 표시하고 같은 입력 단계에 머문다.
   첫 손님의 결과 확인 뒤에는 손님이 보이는 상태에서 튜토리얼 설명창과 회색 오버레이를 빠르게
   디졸브로 걷는다. 밝아진 뒤 첫 손님이 퇴장하고 두 번째 손님이 등장하며, 자리를 잡은 뒤 회색
   오버레이와 다음 안내를 다시 빠르게 디졸브로 표시한다.
5. 두 번째 공격 성향 손님은 카메라를 18,000원에 제시한다.
6. 플레이어가 1원 이상 9,000원 이하의 금액을 직접 입력·제안하고 위협적인 1차 경고를 확인한다.
   키보드와 증감 버튼은 9,000원을 초과한 값도 입력할 수 있지만 Enter 제안 시 범위를 검증한다.
   9,000원 초과이면 `이번에는 위험 신호를 확인하기 위해 9,000원 이하의 금액으로 다시 제안해
   주세요.`를 설명창에 빨간 타자 효과로 표시하고 같은 단계에 머문다. 보유 현금 초과 입력에는
   보유 현금 이하로 다시 제안하라는 안내를 우선 표시한다.
7. 두 번째 손님의 경고 뒤 다른 선택지는 제공하지 않는다. 플레이어가 직전에 입력한 제안가를
   그대로 유지해 재제안을 유도하고, 안내 문구에도 해당 금액을 동적으로 표시한다. 이 거래는
   반드시 손님의 공격과 병원비 지출로 이어지게 한다.
   `과도한 흥정 확인하기` 안내에서는 늑대의 경고 말풍선과 `매입 제안` 버튼을 함께 밝게
   유지한다. 안내창은 두 요소와 겹치지 않는 왼쪽 중단에 배치하고, 안내창 오른쪽에서는
   말풍선으로, 하단에서는 `매입 제안` 버튼으로 각각 분리된 연결선을 표시한다.
   병원비 확인을 누르면 늑대 손님은 새 대사를 시작하지 않고 즉시 퇴장한다.
   결과 단계의 제목은 `공격 결과 확인하기`로 표시하고 `손님 공격` 팝업 전체를 밝게 강조한다.
   튜토리얼에서는 손님의 공격 대사 표시 시간을 기다리지 않고 공격 확정 직후 결과 팝업을 표시한다.
   확인 버튼만 별도로 강조하지 않으며, 안내창과 공격 결과 팝업 전체를 연결선으로 잇는다.
   튜토리얼에서 차감한 병원비는 최종 안내 진입 시 다른 연습 상태와 함께 반환하고 일일 명세서에도
   비용으로 남기지 않는다.
8. 공격 결과 확인 뒤 `신뢰도 알아보기`라는 별도 안내 단계를 표시한다. 상단 신뢰도 라벨·게이지·
   퍼센트 전체를 밝게 강조한다. 거래 성사 시 신뢰도가 오르고 과도한 흥정이 공격·결렬로 끝나면
   거래당 한 번 감소하며, 신뢰도가 높을수록 손님이 더 낮은 제안까지 받아들일 수 있음을 설명한다.
   플레이어가 `다음`을 누르면 화면 전체를 회색 오버레이로 덮고 중앙에 최종 안내창만 표시한다.
   최종 안내는 `손님의 말과 물건 속 단서를 살피고, 신중하고 절묘하게 흥정하며 전당포를
   운영해 보자.`로 표시한다. 이 최종 안내가 나타나는 순간 튜토리얼에서 변한 현금과 병원비·
   매입품·아이템 수량·거래 기록·신뢰도를 모두 DAY 1 시작값으로 복구하고 방문자 큐도 새 5명으로
   초기화한다. `영업 시작` 버튼은 초기화된 일반 플레이를 시작하는 역할만 담당한다. 튜토리얼 중
   방문자 표시는 `1/5명`, `2/5명`으로 사용하고, 실제 영업은 다시 `1/5명`부터 시작한다.
9. 첫 매입 결과는 별도 결과 카드를 만들지 않고 기존 제안가 컨테이너에 `매입 완료 · 물건명 ·
   매입가` 한 줄만 표시한다. 재고 위치·진품 확인 여부와 별도 하단 결과 문구는 표시하지 않는다.
   손님의 최종 반응 말풍선도 함께 밝게 유지하고,
   결과와 안내는 플레이어가 `다음`을 누를 때까지 유지한다. 확인 후 두 번째 손님 튜토리얼로 진행하며, 두 번째 결과까지 확인하면
   세 번째~다섯 번째 손님은 일반 생성·거래 규칙을 사용한다.

## 화면·입력 규칙

- 설명창 문체는 짧은 상황 설명 뒤 `~해 보자`로 다음 행동을 안내하는 방식으로 통일한다.
  한 문장에 여러 규칙을 몰아넣지 않고 의미 단위로 직접 개행하며, 일반 안내는 두 줄로 구성한다.
  첫 가격 입력의 대체 제출 조작과 신뢰도처럼 필수 정보가 세 개인 경우에만 세 줄까지 사용한다.
- 금액 오류 안내도 같은 문체를 사용하며 첫 줄에는 잘못된 이유, 다음 줄에는 허용 범위와
  다시 해야 할 행동을 빨간 타자 효과로 표시한다.

- 캐릭터·말풍선·단서는 가능한 한 밝게 유지하고 현재 배우는 조작 외 버튼을 반투명 회색
  마스크로 덮는다.
- 마스크 영역은 포인터 입력을 차단한다. 강조 영역은 금색 테두리로 표시한다.
- 안내 패널에는 현재 행동과 그 이유를 짧게 표시한다.
- 안내 패널은 화면을 넓게 가리는 중앙 모달 대신 하단의 작은 가죽·황동 카드로 표시한다.
  단계 번호와 짧은 제목, 본문, 다음 행동만 계층적으로 배치하고 `건너뛰기`는 카드 안의
  보조 텍스트 동작으로 둔다.
- 안내 카드와 현재 강조 영역은 얇은 황동 연결선으로 이어 현재 설명이 가리키는 위치를
  한눈에 확인하게 한다. 강조 테두리는 두꺼운 발광 사각형보다 얇고 절제된 금색을 사용한다.
  안내 카드와 강조 영역의 세로 간격이 좁아 연결선이 프레임에 묻히는 경우에는 카드 측면에서
  선을 빼고 대상의 측면으로 우회해, 짧은 선이나 화살촉이 UI 아래에 숨지 않게 한다.
- `말과 물건 상태는 자연스럽다` 안내 단계에서는 단서 영역 전체가 아니라 `물건 관찰` 행을
  직접 강조해, 안내 문구와 플레이어가 확인할 정보를 연결한다. 단서가 하단에 있을 때 안내
  카드는 화면 최상단 HUD 위가 아니라 단서 바로 위의 카운터 하단에 배치해 손님 얼굴과 말풍선을 가리지 않는다.
  연결선은 안내 카드 오른쪽 측면에서 먼저 빠져나온 뒤 아래로 꺾여 `물건 관찰` 영역 상단을
  가리키며, 안내 카드 하단 프레임과 겹치지 않게 한다.
- 첫 `첫날이다. 손님의 말만 믿지 말고` 안내에서는 물건·손님 관찰 단서 상자를 표시하지 않는다.
  플레이어가 `다음`을 누르면 단서 상자가 짧게 나타나고 `물건 관찰` 행을 강조한다.
- 두 번째 손님의 `위험 신호 살펴보기` 첫 안내에서는 거친 말투가 보이는 손님 말풍선과 하단의
  물건·손님 관찰 단서를 동시에 밝게 유지한다. 안내 카드는 두 대상을 가리지 않는 왼쪽 하단에
  배치하고, 안내 카드에서 말풍선과 단서 영역으로 각각 황동 화살표를 연결한다. 단서 연결선은
  안내 카드의 오른쪽 측면에서 시작해 단서 영역의 왼쪽 가장자리를 가로 방향으로 가리킨다.
- 첫 손님의 재제안 단계에서는 `조금만 더 달라`는 손님 반응 말풍선과 제안가 입력 영역을
  동시에 밝게 유지한다. 안내 카드는 말풍선과 제안가 사이의 오른쪽 중단으로 옮기고, 안내 카드에서
  말풍선과 제안가 입력 영역으로 각각 황동 화살표를 연결해 가격 조정의 근거를 함께 보여준다.
- 가격은 자동 조정하지 않는다. 플레이어가 제안가 입력 영역을 선택하고 숫자를 직접 입력하거나
  기존 100원 증감 조작을 사용한다. 첫 제안은 1원 이상 9,000원 이하를 허용하며, 가격 입력
  단계에서 `Enter`를 누르면 별도 중간 확인 단계 없이 해당 금액을 즉시 제안한다.
- 튜토리얼 동안 영업시간은 정지하며 두 번째 손님 결과 확인 후 다시 흐른다.
- 게임 시작 셔터가 완전히 열린 뒤 기본 HUD만 있는 빈 매장을 잠시 표시하고 첫 손님을 디졸브로
  등장시킨다. 손님이 첫 대사를 시작하고 등장이 완료된 다음 첫 튜토리얼 안내를 표시한다.
- 모든 튜토리얼 설명 카드는 같은 높이와 내부 형식을 사용한다. 제목·건너뛰기는 고정된
  머리글에, 본문은 구분선 아래의 고정 시작점에, `다음` 버튼은 고정된 하단 위치에 배치한다.
  본문이 여러 줄이어도 첫 줄이 위로 이동하거나 머리글과 겹치지 않아야 한다.
- 사용자 승인 변경(2026-08-25): 모든 튜토리얼 설명 카드의 머리글 제목은 기존보다 2px,
  `건너뛰기`는 기존보다 4px 아래에 배치한다. 본문·구분선·다음 버튼은 유지한다.
- 튜토리얼이 처음 표시되거나 두 번째 손님 튜토리얼이 다시 시작될 때 마스크·강조선·안내 카드는
  약 0.2초의 짧은 디졸브로 함께 나타난다. 조작을 기다리게 하는 느린 전환은 사용하지 않는다.
- 튜토리얼은 새 게임의 STAGE 1 DAY 1에만 실행한다. 튜토리얼과 실제 영업은 각각 5명 방문자
  카운터를 사용하며, 완료 또는 건너뛰기 시 연습 큐를 제거하고 실제 손님 5명 큐를 새로 시작한다.
- 화면 한쪽에 `튜토리얼 건너뛰기`를 제공한다. 건너뛰면 즉시 마스크와 입력 제한을 해제하고
  연습 중 발생한 모든 상태를 초기화한 뒤 손님 수를 5명으로 다시 구성해 일반 규칙으로 생성한다.
- 감정 아이템은 튜토리얼 진행 여부와 관계없이 실제 DAY 1 영업 시작 시 1개를 보유한다.
- 튜토리얼이 활성화된 동안 특수 아이템 카드와 재고 아이템에 마우스를 올려도 별도 설명
  툴팁을 표시하지 않는다. 튜토리얼 안내가 현재 행동 설명을 단독으로 담당한다.
- 사용자 승인 변경(2026-08-24): 모든 튜토리얼 설명 카드에서 원형 단계 배지와 단계 숫자를 제거하고 제목을 카드 왼쪽 기준선에 정렬한다.
