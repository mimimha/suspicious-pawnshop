# PRD 5-4 — 손님 유형·신뢰도·조기 결렬

> 출처: Notion `통합 기획서` §8·§11·§21·§25~26, `거래·흥정 규칙` §2·§4·§6~7·§12·§15·§18
> 작성일: 2026-08-19 (Notion 기준 2026-08-18T14:47Z)

## 목표

반복 등장하는 손님별 신뢰도와 숨겨진 성향을 적용해 최저 수용 가격, 가품 확률, 낮은 제안의 조기 결렬을 변화시킨다.

### 사용자 승인 변경 — 추리 단서

- 손님 유형마다 거래가 반복돼도 유지되는 말투와 행동 패턴을 둔다. 정직형은 구체적이고
  차분하게, 일반형은 중립적으로, 의심형은 짧고 경계하는 말투로, 사기형은 과장·재촉하는
  말투로 반응한다.
- `차분히`, `담담히`, `경계하며`, `재촉하듯` 같은 성향 표지는 말풍선 문장 앞에 직접 붙이지
  않는다. 성향은 이름별 대사 자체와 `손님 관찰` 정보로 전달한다.
- 거래 화면에는 물건의 마감·사용감 관찰 1개와 손님의 행동 단서 1개만 선명하게 표시한다.
- 물건 단서는 거래마다 상태·희귀성·현재 시장 흐름 중 하나를 선택해 표시하며, 손님 행동
  단서와 합쳐 최대 2개 원칙을 유지한다.
- 단서는 진품·가품이나 손님 유형을 직접 판정하지 않으며 감정권 사용 여부와 제안 위험을
  스스로 판단하는 참고 정보로만 사용한다.

## 범위

- 손님 이름별 신뢰도를 0~100으로 보유하고 STAGE/DAY를 넘어 유지한다.
- 시작 신뢰도는 현재 테스트값 50이다.
- 사용자 승인 변경: 최저 수용가는 최초 희망가에서 유형별 할인율(정직 28~34%, 일반
  30~38%, 의심 32~42%, 사기 35~45%)을 적용한다. (2026-08-24 조정) 신뢰도는 할인율에 0~20 -3%p,
  21~40 -1.5%p, 41~60 0%p, 61~80 +1.5%p, 81~100 +3%p를 보정한다.
- 손님 유형은 정직형·일반형·의심형·사기형이며 이름별로 유지하고 숫자/유형명은 숨긴다.
- 유형별 가품 보정은 -5%p, 0, +10%p, +20%p다.
- 거래 화면에는 이름과 신뢰도 퍼센트, 성향을 암시하는 한 줄 대사만 표시한다.
- 거래 성공 +5, 직접 거절 -3, 불만 제안은 라운드별 -2/-3/-4, 최종 결렬 -5, 재고 부족 취소 -5를 현재 테스트값으로 적용한다.
- 최저가 미만 제안은 반응·라운드·유형에 따른 조기 결렬 확률을 가진다. 모든 확률은 config에 둔다.

## 완료 조건

1. 같은 이름의 신뢰도와 유형이 DAY/STAGE를 넘어 유지된다.
2. 신뢰도가 최저 수용 가격에 정확히 반영된다.
3. 유형이 STAGE 2 가품 확률에 반영된다.
4. 거래 결과와 불만 제안이 신뢰도를 0~100 안에서 변경한다.
5. 1·2회차에도 config 확률로 거래가 결렬될 수 있다.
6. 신뢰도는 공개하고 유형과 확률은 직접 공개하지 않는다.
