# PRD 5-7 — 전체 물건 풀·희귀도·재고 이동

> 출처: Notion `통합 기획서` §15~19, `재고·판매·시세 규칙` §1~3·§6
> 작성일: 2026-08-19 (Notion 기준 2026-08-18T14:47Z)
> 사용자 승인 변경: 2026-08-19 제공 매입품 에셋 9종으로 등장 목록 교체
> 사용자 승인 변경: 2026-08-25 물건 풀 확장(STAGE 1 개방 + 신규 9종 등록), 희귀도 사다리 정리

## 목표

데모의 6개 카테고리별 물건 풀과 희귀도를 적용하고, 재고 3×3 안에서 보유 물건 위치를 바꿀 수 있게 한다.

## 범위

- 사용자 제공 에셋과 이름이 일치하는 9개 물건을 카탈로그에 등록한다.
- **사용자 승인 변경(2026-08-25)** STAGE 1은 아트가 있는 9종을 모두 사용한다.
  기존 6종만으로는 하루 5명 x 3일 동안 같은 물건이 돌아 다양성이 없었다.
  STAGE 2 전용 자리는 아래 신규 물건이 이어받는다.
- **사용자 승인 변경(2026-08-25)** 신규 물건 9종(STAGE 1 4종 / STAGE 2 5종)의
  이름·카테고리·기준가·희귀도를 카탈로그와 관찰 단서에 등록한다.
  아트(`public/assets/items/<id>.webp`)가 없는 동안은 `artReady: false`로 두어
  추첨에서 제외하고, 파일을 넣고 플래그만 바꾸면 그대로 등장한다.
- 개별 기준가는 현재 테스트값이며 희귀도와 사다리를 맞춘다.
  일반 5,500~10,000 / 고급 12,000~18,000 / 희귀 18,000~32,000 / 전설 25,000~46,000.
  기준가 35,000인 고서적이 희귀로 묶여 사다리가 어긋나 있어 전설로 옮겼다.
- **사용자 승인 변경(2026-08-25)** 희귀도 등장 비중은 일반 42%, 고급 30%, 희귀 20%, 전설 8%다.
  풀이 커지면서 전설 5%로는 개별 전설 물건이 한 STAGE 내내 한 번도 안 나오는 수준이었다.
- 희귀도는 고객 물건 생성 가중치와 표시 정보에 포함하며 진품·가품과 독립적이다.
- 희귀도가 높은 시드는 더 높은 기준가를 갖게 데이터로 구성하며 별도의 런타임 가격 배율은 중복 적용하지 않는다.
- 재고 팝업에서 물건 칸을 선택한 뒤 다른 물건 또는 빈칸을 선택하면 위치를 이동하거나 교환한다.
- 위치 이동은 판매가나 게임 효과에 영향을 주지 않는다.

## 완료 조건

1. 사용자 제공 에셋과 이름이 일치하는 9개 물건과 6개 카테고리가 생성 풀에 포함된다.
2. STAGE 1에서 아트가 있는 9종이 모두 등장하고, 아트가 없는 물건은 등장하지 않는다.
3. STAGE 2에서 기존 물건과 고가 물건이 모두 등장한다.
4. 희귀도 가중치와 가격 배율이 config로 분리된다.
5. 희귀도는 진품 여부와 독립적으로 저장·표시된다.
6. 재고 슬롯을 빈칸으로 이동하거나 서로 교환해도 물건 데이터가 유지된다.
