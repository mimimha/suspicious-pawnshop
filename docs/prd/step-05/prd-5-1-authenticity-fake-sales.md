# PRD 5-1 — 전 STAGE 진품·가품과 처분가

> 출처: Notion `통합 기획서` §2·§20~24, `물건·감정 규칙` §9~11·§15·§18·§23·§25~27, `재고·판매·시세 규칙` §2·§5·§7
> 작성일: 2026-08-19 (Notion 페이지 기준 시각 2026-08-18T14:47Z)
> 이전 PRD: `docs/prd/step-04/prd-4-2-rent-stage-result.md`

## 목표

STAGE 1부터 손님이 가져오는 물건의 진품·가품 여부를 등장 시점에 확정한다. 거래 전에는
숨기며, 가품은 일반 시세와 무관하게 기준가의 40%로 처분해 첫 STAGE부터 감정 판단을 만든다.

## 사용자에게 보이는 최소 플레이 흐름

```text
STAGE 1부터 손님 등장
  → 카테고리별 확률로 진품·가품 확정
  → 거래 중 결과 비공개
  → 구매 성사
  → 진품 또는 가품 즉시 공개
  → 재고에 결과 저장
  → DAY 시작 판매 또는 보따리 상인 판매
      진품: 기존 시세/상인 제안가
      가품: 기준가의 40% 고정 처분가
```

## 구현 범위

### 1. Authenticity 생성

- `genuine | fake` 두 상태를 사용한다.
- 모든 STAGE에서 손님에게 물건이 배정되는 순간 카테고리별 가품 확률로 결과를 한 번 결정한다.
- 결정된 결과는 거래 중 바뀌지 않는다.
- 난수 공급자를 주입할 수 있어 경계값을 단위 테스트한다.
- 아직 손님 유형이 없으므로 손님 유형별 확률 보정은 적용하지 않는다.

### 2. 카테고리별 기본 가품 확률

| 카테고리 | 가품 확률 |
| --- | ---: |
| 생활용품 | 7% |
| 전자기기 | 13% |
| 취미용품 | 14% |
| 수집품 | 18% |
| 액세서리 | 21% |
| 골동품 | 25% |

- 사용자 승인 변경(2026-08-26): 기존 10~35%(평균 23%)에서 일괄 0.7배로 낮췄다.
  시세 평균 배수가 1.0이라 물건의 기대 가치는 `기준가 x (1 - (1 - 처분비율) x 가품확률)`이고,
  평균 23%에서는 손익분기 매입가가 기준가의 86%(최초 제시가의 80%)였다.
  최초 제시가의 80~100%를 부르는 플레이는 모두 평균 손해인데, 그 구간이 전부 손님이 즉시
  수락하는 무저항 구간이라 플레이어가 손해를 배울 수 없었다.
  평균 16%로 낮춰 손익분기를 최초 제시가의 84%로 올렸다. 처분 비율(40%)은 그대로 둬서
  가품 한 건의 타격은 유지한다. 더 드물지만 여전히 아프다.

- 확률은 `src/config/`에서 카테고리별 데이터로 관리한다.
- 사용자 승인 변경(2026-08-26): 카테고리별 위조 위험을 시세 장부 하단에 정성 등급으로 표시한다.
  확률 숫자는 노출하지 않는다. 물건의 값과 진위 추측이 핵심이므로 확률을 알려 주면 흥정이
  계산으로 바뀐다. 반면 카테고리 위험은 전당포 주인의 일반 상식이라 알려 주는 것이 자연스럽다.
  등급은 카테고리를 확률 순으로 줄 세워 세 단계(드묾·보통·잦음)로 균등 분할하고,
  위험이 낮은 순서로 그린다. 개별 물건의 진위는 계속 감정 도구로만 확인한다.

### 3. 거래와 구매 결과 공개

- 거래 중 물건명·카테고리·희망 가격은 기존대로 표시하고 진품 여부는 숨긴다.
- 사용자 승인 변경(2026-08-23): 진품과 가품 모두 동일한 개수와 형식의 물건·손님 관찰 정보를
  제공한다. 가품일 때만 단서를 비우거나 숨기지 않으며, 단서의 내용만 추론 재료로 사용한다.
- 사용자 승인 변경(2026-08-23): 물건 관찰은 9종 각각의 실제 관찰 부위를 바탕으로 `자연스러움`,
  `판단 보류`, `의심` 세 방향을 사용한다. 진위와 일치하는 방향은 60%, 판단 보류는 25%, 반대
  방향은 15%의 현재 테스트값으로 제공한다. 어느 문구도 진품·가품을 직접 언급하지 않으며,
  플레이어는 손님 행동·가격·감정 도구와 함께 판단한다.
- 사용자 승인 변경(2026-08-23): 모든 거래의 하단 단서 형식은 `물건 관찰`과 `손님 관찰` 두 줄로
  고정한다. 희귀성이나 시장 상황이 물건 상태 단서를 무작위로 대체하지 않으며, 해당 정보는
  시세 장부·판매·물건 정보처럼 목적에 맞는 별도 영역에서 제공한다.
- 사용자 승인 변경(2026-08-25): 플레이어가 배워야 하는 판단 기준을 하나로 정한다.
  **부위끼리 흔적이 서로 이어지는가.** `자연스러움`은 서로 다른 부위의 흔적이 하나의
  사용 이력으로 이어지고, `의심`은 겉면은 낡았는데 손이 가장 많이 닿는 곳만 새것이거나
  각인 서체·규격·무게가 시대와 어긋난다. `판단 보류`는 수리·부품 교체·보관 상태처럼
  진품·가품 양쪽에서 똑같이 흔한 사실만 말한다. 이전 문구는 `판단 보류`가 사실상
  가품 신호를 담고 있어 세 방향이 구분되지 않았다.
- 사용자 승인 변경(2026-08-25): 물건별 문구를 어조마다 3가지로 늘리고, 세 문구가 서로 다른
  관찰 축(마모 위치 / 각인·서체 / 이음새·제작 흔적 / 무게·소재감 / 산화 균일성 / 냄새·소리 /
  부속·수리 이력)을 쓰게 한다. 한 가지 요령만 외우고 끝나지 않게 하기 위함이다.
  어조 굴림과 문구 변형 굴림은 독립적으로 정해 같은 물건이 다시 나와도 문장이 반복되지 않게 한다.
- 사용자 승인 변경(2026-08-25): `손님 관찰`도 유형별 1문장에서 3문장으로 늘린다.
- 가격 수락 뒤 현금·재고 조건까지 충족해 구매가 확정된 순간 진품·가품 결과를 표시한다.
- 거래 거절·결렬·현금 부족·재고 부족이면 결과를 공개하지 않는다.
- 구매 결과 안내가 끝나면 기존 손님 대기 흐름으로 돌아간다.
- 감정 버튼과 감정권 소비는 PRD 5-2 범위다.

### 4. 재고 저장과 표시

- 재고 인스턴스가 실제 진품 여부를 소유한다.
- 같은 종류 물건도 각 인스턴스의 진품 여부가 다를 수 있다.
- 재고 상세에 `진품` 또는 `가품`을 표시한다.
- STAGE/DAY가 바뀌어도 진품 여부를 유지한다.

### 5. 가품 판매 가격

- 가품 처분가는 `기준가 × 40%`다.
- 100원 단위로 반올림한다.
- 일반 시세 배율과 전날 대비 시세 상태의 영향을 받지 않는다.
- DAY 시작 판매창에서 가품을 선택하면 고정 처분가와 손익을 표시한다.
- 사용자 승인 변경(2026-08-25): 가품의 최근 시세 그래프도 진품과 동일하게 현재까지 누적된
  DAY 수만큼 점과 날짜 라벨을 표시하되, 모든 점을 고정 처분가 높이에 두어 수평선으로 연결한다.
- 보따리 상인에게 가품을 판매할 때도 상인의 변동 제안가 대신 같은 고정 처분가를 적용한다.
- 진품 판매와 상인 판매는 기존 규칙을 유지한다.

## 시스템 책임

- **Authenticity 규칙**: STAGE·카테고리·난수로 진품 여부 결정.
- **Customer**: 등장한 물건의 숨겨진 진품 여부 보유.
- **Inventory**: 구매 후 공개된 진품 여부를 인스턴스별 저장.
- **Market / BagMerchant 판매 처리**: 진품과 가품에 맞는 판매가 선택.
- **DayScene**: 구매 결과와 재고·판매 UI 표시.

## 완료 조건

1. STAGE 1부터 물건은 카테고리별 config 확률로 진품·가품이 정확히 한 번 결정된다.
3. 거래 중 진품 여부가 노출되지 않는다.
4. 실제 구매 성사 시에만 진품·가품 결과가 공개된다.
5. 구매한 결과가 재고 인스턴스에 저장되고 DAY/STAGE 이월 뒤에도 유지된다.
6. 같은 종류의 진품과 가품을 서로 다른 재고로 보유할 수 있다.
7. 가품 일반 판매가는 기준가의 40%이며 시세 배율의 영향을 받지 않는다.
8. 가품 보따리 상인 판매도 기준가의 40% 고정 처분가를 사용한다.
9. 진품의 기존 일반 판매·상인 판매 가격은 변하지 않는다.
10. 판매창과 재고 상세에서 가품 여부·처분가·손익을 확인할 수 있다.
11. 기존 전체 테스트와 `npm run typecheck`, `npm run build`, `npm test`가 통과한다.

## 기획 충돌 해석

Notion의 보따리 상인 페이지는 진품 기준 변동 제안가를 정의하고, 물건·감정 페이지는 가품을 기준가 10%로 처분하도록 정의한다. 이 PRD에서는 가품 가치 규칙을 우선하여 일반 판매와 보따리 상인 모두 같은 고정 처분가를 적용하며, 비율은 플레이테스트로 40%까지 올렸다.

## 승인 시 확정되는 사항

1. STAGE 2 가품은 우선 카테고리 확률만 적용한다.
2. 구매가 최종 성사된 순간 결과를 공개한다.
3. 가품은 일반 판매와 보따리 상인 모두 기준가 40%로 처분한다.
4. 거래 전 감정은 다음 PRD 5-2에서 구현한다.
