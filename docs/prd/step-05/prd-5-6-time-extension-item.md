# PRD 5-6 — 장사 시간 증량 아이템

> 출처: Notion `통합 기획서` §29·§32·§34, `아이템·월세·보따리 상인` §1~2
> 작성일: 2026-08-19 (Notion 기준 2026-08-18T14:47Z)

## 목표

모든 STAGE 종료 상점에서 모래시계를 구매하고 아이템 창에서 사용해 당일 영업시간을 30초 늘린다.

### 사용자 승인 변경 — 전용 아이템 아이콘

- 모래시계는 기존 매입품 회중시계 그림을 재사용하지 않고, 자주색 모래와 황동 프레임을 가진
  전용 모래시계 아이콘을 사용한다.
- 같은 전용 아이콘을 아이템 상점과 영업 중 아이템 창에서 공통으로 사용한다.

## 범위

- 현재 테스트값 가격 3,000원, 상점 방문당 1개, 소모형으로 보유한다.
- 모든 STAGE의 영업 중 아이템 창에서 한 개를 사용할 수 있다.
- 사용할 때마다 해당 DAY 영업시간이 30초 증가하며, 보유 수량만큼 다시 사용할 수 있다.
- 수량은 DAY/STAGE를 넘어 유지하고 새 게임에서 0개다.
- 상점 구매 비용은 아이템 구매 장부에 포함한다.

## 완료 조건

1. 구매·보유·소비가 다른 아이템과 독립적이다.
2. 영업 중 사용할 때마다 현재 남은 타이머가 즉시 30초 증가하고 한 개씩 소비한다.
3. 사용하지 않은 수량은 유지된다.
4. STAGE와 관계없이 영업 중 사용할 수 있다.

## 범위 밖

- 시간 아이템 중첩 사용
- 전용 아트·연출·사운드
