# PRD 5-3 — 시세 확인권과 다음 DAY 예상 판매가

> 출처: Notion `통합 기획서` §29·§30·§34, `재고·판매·시세 규칙` §1·§4~5, `아이템·월세·보따리 상인` §1~2, `아이템 UI`, `시세 확인 및 판매 팝업`
> 작성일: 2026-08-19 (Notion 페이지 기준 시각 2026-08-18T14:47Z)
> 이전 PRD: `docs/prd/step-05/prd-5-2-appraisal-ticket.md`

## 목표

모든 DAY 종료 상점에서 시세 확인권을 구매하고, 사용할 수 있는 다음 DAY 시작 판매창에서 재고 물건 하나에 사용해 그 물건의 다음 DAY 실제 판매가를 미리 확인할 수 있게 한다. 플레이어가 오늘 판매할지 하루 더 보관할지 제한된 정보로 판단하게 한다.

### 사용자 승인 변경 — 전용 아이템 아이콘

- 시세 수첩은 기존 매입품 안경 그림을 재사용하지 않고, 가격 등락선과 전당포 표식이 있는
  작은 가죽 시세 장부 전용 아이콘을 사용한다.
- 같은 전용 아이콘을 아이템 상점과 영업 중 아이템 창에서 공통으로 사용한다.

## 사용자에게 보이는 최소 플레이 흐름

```text
모든 STAGE의 DAY 종료
  → 아이템 상점
  → 시세 확인권 3,000원에 최대 1개 구매
  → DAY 2 시작 판매창
  → 재고 물건 선택
  → [시세 확인권 사용]
  → 시세 확인권 1개 차감
  → 내일 실제 판매가와 예상 손익 표시
  → 오늘 판매 또는 보관 결정
```

## 구현 범위

### 1. SpecialItemInventory 확장

- 시세 확인권 수량을 감정권과 별도로 보유한다.
- 새 게임에서는 0개로 시작한다.
- 구매한 수량은 DAY와 STAGE를 넘어 유지한다.
- 사용 시 1개를 즉시 차감하고 반환하지 않는다.
- 일반 매입품 재고 3×3 공간을 사용하지 않는다.

### 2. 모든 DAY 종료 아이템 상점 확장

- 사용자 승인 시각 변경(2026-08-23): 아이템 상점은 확정된 시작 로고와 일일 명세서의
  검정 목재·낡은 황동·자주색 가죽·오래된 종이 문법으로 재디자인한다. 기능과 상품 배치는
  유지하되 상점 전체가 전당포의 펼친 카탈로그 장부처럼 보이도록 구성한다.
- 먼저 완성 목업으로 시각 구성을 확인하고, 승인 후 프레임·상품 카드·상세 패널·구매 버튼 등
  런타임용 에셋을 분리한다. 상품명·보유 수량·가격·설명은 이미지에 포함하지 않는다.

- 모든 STAGE의 DAY 1·2·3 종료 상점에 감정권과 시세 확인권을 함께 표시한다.
- 시세 확인권 가격은 현재 테스트값 3,000원이다.
- 방문마다 시세 확인권을 최대 1개 구매할 수 있다.
- 감정권과 시세 확인권을 같은 방문에 각각 한 개씩 구매할 수 있다.
- 현금이 부족하거나 해당 품목을 이미 구매했다면 그 구매 버튼만 비활성화한다.
- 구매 시 현금 차감, 시세 확인권 증가, DailyLedger `아이템 구매` 기록을 각각 한 번 수행한다.
- 구매 결과는 구매 버튼의 활성·비활성 및 `구매 완료` 상태로만 표시한다. 상세 영역 하단의
  메시지 슬롯은 사용하지 않으며 구매 성공·보유 수량·현금 부족·구매 오류 등 어떤 상태
  문구도 그 위치에 표시하지 않는다.
- 기존처럼 상점을 나간 뒤 다시 열 수 없다.
- DAY 1·2는 영업 종료 직후 상점을 열고, 상점을 닫은 뒤 일일 명세서로 이어진다.
- DAY 3은 `보따리 상인 방문 → 셔터 재하강 → 아이템 상점 → STAGE 정산` 순서로 이어진다.
- 상점 UI는 화면 가장자리 전체를 두르는 상점 외곽 프레임, 네 상품 전체를 감싸는 하나의
  상품 목록 프레임, 선택 상품 상세 영역을 주요 컨테이너로 사용한다. 중앙의 `아이템 상점`
  제목은 별도 명패 컨테이너 없이 배경 위에 직접 표시한다. 상품 목록 프레임은 얇은 황동
  외곽선으로 영역 경계를 분명히 표시한다.
- 각 상품의 이미지·이름·보유 수량·가격은 하나의 상품 영역 안에서 구분하되, 각각을 별도
  박스로 다시 감싸지 않는다. 가격은 얇은 구분선과 금화 아이콘으로, 보유 수량은 작은
  텍스트 배지로 표시해 중첩 프레임을 최소화한다.
- 선택 강조는 상품 칸 전체를 덮는 큰 자주색 면을 사용하지 않는다. 장부 종이에 인쇄된 중앙 가로
  구분선은 제거하고, 네 상품 사이에 작은 간격만 남는 확대된 런타임 셀에 얇은 황동 테두리와 매우
  약한 자주색 음영을 표시한다. hover는 같은 표시를 낮은 강도로 보여준다. 우측 상세 영역에서도
  제목·설명·수량·합계를 개별 컨테이너로 나누지 않는다.
- 사용자 승인 변경(2026-08-23): 상품 칸은 펼친 책의 사분면 전체가 아니라 종이에 미세하게
  인쇄된 네 개의 내부 사각선 안쪽을 기준으로 한다. 선택 배경과 클릭 영역은 이 선을 넘지 않으며,
  이미지·상품명·보유량·가격도 동일한 내부 영역의 공통 중심선과 세로 간격에 맞춘다. 장부 이미지는
  원본 종횡비를 유지해 인쇄선이 늘어나지 않게 표시한다.
- 2026-08-20 사용자 제공 레퍼런스를 기준으로 상점은 1280×720 화면 대부분을 채운다. 상단에는
  `STAGE · DAY 종료`, 중앙 `아이템 상점`, 우측 보유 현금과 닫기 버튼을 배치한다. 좌측 2×2
  상품 진열은 이미지·이름·보유 수량·가격을 표시하고, 우측 상세에는 선택 상품의 큰 이미지,
  설명, 합계와 보라색 구매 버튼을 세로로 배치한다. 하단에는 다음 영업일부터 사용할 수 있다는
  안내를 표시한다.
- 우측 상세 시트의 설명·가격·구매 버튼은 시트 안쪽 안전 여백을 넘지 않으며, 설명은 고정 폭과
  명시적 개행으로 상품마다 같은 영역 안에 표시한다. 구매 버튼은 상세 시트 폭보다 짧게 유지한다.
- 상품 진열은 시세 확인·시간 증량 아이템을 위쪽에, STAGE 1부터 구매 가능한 감정도구·방어
  부적을 아래쪽에 배치한다. 모든 상품은 방문당 항상 한 개만
  구매하므로 우측 단가 표기는 `합계`가 아니라 `가격`을 사용한다.

### 3. 다음 DAY 시세 선결정

- Market은 현재 DAY 시세가 만들어질 때 다음 DAY 카테고리별 시세도 내부적으로 한 번만 미리 결정한다.
- 시세 확인권이 보여주는 가격은 추정 범위가 아니라 다음 DAY에 실제 적용될 정확한 판매가다.
- 다음 DAY로 넘어가면 미리 결정했던 시세가 현재 시세가 되며 다시 추첨하지 않는다.
- 시세 확인권을 사용하지 않아도 다음 DAY 시세는 같은 방식으로 미리 결정되어 결과가 달라지지 않는다.
- 플레이어에게 내부 배율이나 카테고리 전체의 다음 DAY 시세는 공개하지 않는다.

### 4. 판매창에서 시세 확인권 사용

- 모든 STAGE의 마지막 DAY를 제외한 DAY 시작 판매창에서 사용할 수 있다.
- 판매창에서 보유 재고 물건 하나를 선택하면 `다음날 시세 예측` 버튼을 표시한다.
- 수량이 0개면 비활성 상태와 `시세 확인권 없음` 안내를 표시한다.
- 사용자 승인 변경(2026-08-24): 가품을 선택하면 `다음날 시세 예측` 버튼은 보이되 비활성화하고
  시세 수첩을 소비하거나 예상가를 기록하지 않는다.
- 버튼에 마우스를 올리면 어두운 말풍선형 안내 상자에 `시세 수첩 아이템이 있다면 다음날의
  시세를 미리 알 수 있습니다.`를 표시한다. 가품 선택 시에는 가품의 판매가가 고정되어 사용할 수
  없다는 이유를 대신 안내한다.
- 사용하면 선택한 물건에 대해 시세 확인권 1개를 즉시 차감한다.
- 같은 물건은 같은 판매창에서 두 번 확인할 수 없다.
- 가품에는 사용할 수 없다. 가품은 시세와 무관하게 기준가 10%의 고정 처분가를 사용한다.
- 각 STAGE의 마지막 DAY에는 같은 STAGE의 다음 DAY가 없으므로 버튼은 비활성 상태로 표시하고
  다음 DAY가 없어 사용할 수 없다는 hover 안내를 제공한다.

### 사용자 승인 변경 — 판매창 장부형 UI

- 판매창은 아이템 구매 창과 같은 검정 목재·황동·빛바랜 종이 재질로 통일한다.
- 왼쪽 종이에는 실제 보유 매입품만 행으로 표시하며 빈 슬롯은 표시하지 않는다.
- 오른쪽 상세지에는 선택 물건 이미지, 현재 판매가, 매입가, 손익과 최근 시세 그래프를 표시한다.
- 고정 프레임·선택 행·페이지 버튼·행동 버튼은 분리 이미지로 사용하고 아이템·가격·그래프·페이지·
  버튼 문구는 런타임 상태에 따라 코드로 표시한다.
- 하단에는 `다음날 시세 예측`, `판매`, `영업 시작` 행동을 같은 높이로 배치한다.
- 사용자 승인 변경: 하단 세 행동 버튼은 크기와 가로 정렬을 유지한 채 기존 위치에서 5px 위로 배치한다.
- 선택 행의 포인터 장식은 행 본체와 분리해 행 본체의 좌우 여백이 동일하게 보이도록 배치한다.
- 사용자 승인 변경(2026-08-25): 판매 목록의 좌우 페이지 이동은 사각 배경·테두리 없이
  화살표만 표시한다. 기존 클릭 영역과 페이지 이동 기능은 유지한다.
- 판매 완료 시 일반 상세 텍스트 대신 거래 완료 패널을 표시해 물건명·매입가·판매가·실현 손익·보유일을
  한눈에 확인할 수 있게 한다.
- 사용자 승인 변경(2026-08-24): 보유일은 매입일을 포함해 세지 않고 매입 DAY부터 판매 DAY까지
  실제로 경과한 날짜 차이로 계산한다. 따라서 DAY 1 매입 후 DAY 2 판매는 `보유 1일`, 같은 DAY
  매입·판매는 `보유 0일`로 표시한다. STAGE가 바뀌어도 STAGE당 DAY 수를 반영해 같은 기준을 유지한다.

### 5. 예상가 표시와 수명

- 확인한 물건의 상세 정보에 `내일 판매가`와 `내일 예상 손익`을 표시한다.
- 사용자 승인 변경(2026-08-24): `내일 예상`은 현재 손익·시세 방향 줄 바로 다음 줄에 같은
  줄 간격으로 표시하며 별도의 빈 줄을 두지 않는다.
- 최근 시세 그래프의 `2일 전`·`어제`·`오늘` 라벨은 종이 배경에서 충분히 읽히는 진한 갈색과
  굵은 글꼴을 공통 적용한다.
- 결과는 해당 DAY의 판매창을 닫기 전까지만 유지한다.
- 판매창을 닫으면 모든 확인 결과를 지우고, 재고 화면이나 영업 중에는 표시하지 않는다.
- 확인한 물건을 즉시 판매하면 기존 판매 흐름대로 재고에서 제거한다.
- 결과 확인 팝업이나 시간 정지는 추가하지 않는다. DAY 시작 판매창은 아직 영업시간이 흐르지 않는 구간이다.

## 범위 밖

- 시세 방향만 보여주는 별도 예보 등급
- 카테고리 전체 또는 여러 물건을 한 장으로 확인
- DAY 3 이후 STAGE 3 예상가
- 장사 시간 증량 아이템과 방어 아이템
- 아이템 전용 이미지·애니메이션·사운드
- 아이템 가격 재조정

## 시스템 책임

- **SpecialItemInventory**: 시세 확인권 보유·구매·소비 수량.
- **ItemShopVisit**: 품목별 방문당 구매 제한과 구매 처리.
- **Market**: 현재/다음 DAY 시세 선결정, 다음 DAY 가격 계산, DAY 전환 시 승격.
- **DayScene 판매창**: 선택 물건 사용 요청과 해당 판매창 동안의 공개 결과 표시.
- **DailyLedger**: 시세 확인권 구매 비용 기록.

## 완료 조건

1. 새 게임과 STAGE 1의 시세 확인권 수량은 0개다.
2. 모든 DAY 종료 상점에서 시세 확인권을 3,000원에 방문당 한 개 살 수 있다.
3. 같은 방문에서 감정권과 시세 확인권을 각각 한 개 구매할 수 있다.
4. 구매 시 현금·시세 확인권·장부가 정확히 한 번 변경된다.
5. 현금 부족과 동일 품목 중복 구매는 상태 변경 없이 거부된다.
6. 미리 결정된 다음 DAY 시세는 확인권 사용 여부와 무관하게 실제 다음 DAY 시세와 일치한다.
7. 모든 STAGE의 마지막 DAY를 제외한 판매창에서 선택한 재고 하나에만 시세 확인권을 사용할 수 있다.
8. 사용 시 수량이 즉시 1개 감소하고 같은 물건의 중복 확인을 막는다.
9. 확인 후 내일 판매가와 내일 예상 손익이 표시된다.
10. 가품의 내일 판매가는 현재와 동일한 기준가 10% 처분가다.
11. 판매창을 닫으면 공개 결과가 지워지고 영업·재고 화면에 노출되지 않는다.
12. 각 STAGE의 마지막 DAY에는 사용 버튼이 비활성 상태로 나타나고 다음 DAY가 없다는 안내를 표시한다.
13. DAY/STAGE 전환 시 미사용 시세 확인권은 유지된다.
14. 기존 전체 테스트와 `npm run typecheck`, `npm run build`, `npm test`가 통과한다.

## 사용자 승인 시각 변경 — 상점 상세 시트 세로 압축

- 아이템 상점 우측 상세 시트의 표시 높이를 550px에서 520px로 30px 줄인다.
- 구매 버튼은 190×50px로 축소하고 기존 보정 위치에서 추가로 30px 위로 올려, 시트 하단 밖으로 나가지 않도록 안정적인 내부 여백을 둔다.
- 제목·아이콘·설명·가격·버튼이 겹치지 않도록 아이콘과 간격을 함께 압축하며, 긴 설명은 필요한 경우에만 글자 크기를 축소한다.
- 상세 시트의 가로 크기, 색상·채도, 상품 정보와 구매 기능은 유지한다.
- 구매 버튼 에셋 하단에 포함된 회색 반투명 그림자는 제거하고 가죽·황동 버튼 본체만 표시한다.
