# PRD 5-2 — 감정권 상점과 거래 전 감정

> 출처: Notion `통합 기획서` §23·§29·§32·§34, `물건·감정 규칙` §12~16·§30·§32, `전당포 게임 기획 개요` §2·§4, `아이템·월세·보따리 상인` §1~2
> 작성일: 2026-08-19 (Notion 페이지 기준 시각 2026-08-18T14:47Z)
> 이전 PRD: `docs/prd/step-05/prd-5-1-authenticity-fake-sales.md`

## 목표

STAGE 1부터 DAY 종료 후 감정권을 구매하고, 다음 영업의 가격 제안 전에 사용해 손님 물건의
진품·가품 여부를 확인할 수 있게 한다.

### 사용자 승인 변경 — 전용 아이템 아이콘

- 감정 아이템은 기존 매입품 돋보기 그림을 재사용하지 않고, 보석 감정용 루페와 감정 기록표를
  결합한 전용 아이콘을 사용한다.
- 같은 전용 아이콘을 아이템 상점과 영업 중 아이템 창에서 공통으로 사용한다.
- 감정 결과 팝업 제목은 공통 목재·황동 결과 프레임의 상단 장식과 겹치지 않도록 기존 위치에서
  10px 아래에 표시한다.

## 사용자에게 보이는 최소 플레이 흐름

```text
모든 STAGE의 DAY 1·2·3 영업 종료
  → 감정권 상점
  → 3,000원에 최대 1개 구매 또는 건너뛰기
  → 일일 명세서
  → 다음 DAY

손님 등장
  → 가격 제안 전 [감정권 사용]
  → 감정권 1개 즉시 차감
  → 영업시간 정지
  → 진품 / 가품 결과 팝업
  → 확인 후 영업시간 재개
  → 흥정 또는 거래 포기
```

## 구현 범위

### 1. SpecialItemInventory

- Phaser에 의존하지 않는 아이템 보유 시스템이 감정권 수량을 소유한다.
- 수량은 0 이상의 정수다.
- 새 게임은 STAGE 1 첫 거래부터 감정을 경험할 수 있도록 튜토리얼용 감정권 1개로 시작한다.
- 구매한 감정권은 DAY와 STAGE를 넘어 유지한다.
- 사용 시 1개를 즉시 차감하며 거래 결과와 관계없이 반환하지 않는다.
- 재고 3×3 매입품 칸과는 별도이며 공간을 차지하지 않는다.

### 2. 모든 DAY 종료 아이템 상점

- STAGE와 DAY 구분 없이 모든 영업 종료 뒤 상점 화면을 한 번 열며 STAGE 1부터 감정권을 구매할 수 있다.
- 감정권 가격은 현재 테스트값 3,000원이다.
- 상점 방문마다 최대 1개만 구매할 수 있다.
- 현금이 부족하면 구매 버튼을 비활성화하고 이유를 표시한다.
- 구매 시 현금을 즉시 차감하고 감정권 수량을 1 증가시킨다.
- 구매 비용은 해당 DAY DailyLedger의 `아이템 구매` 항목에 기록한다.
- 구매 또는 건너뛰기 후 상점을 다시 열 수 없다.
- 상점 종료 뒤 기존 일일 명세서를 표시하고 다음 DAY로 진행한다.
- 마지막 DAY에는 보따리 상인 거래와 셔터 재하강 뒤 상점이 열리며, 상점을 닫은 뒤 STAGE 정산 흐름으로 이어진다.

### 3. 거래 전 감정

- 모든 STAGE에서 활성 손님이 있고 아직 가격을 한 번도 제안하지 않았을 때만 `감정권 사용` 버튼을 표시한다.
- 감정권이 0개면 버튼은 비활성 상태와 `감정권 없음` 안내를 표시한다.
- 버튼을 누르면 감정권을 즉시 1개 차감하고 현재 고객 물건의 이미 확정된 진품 여부를 공개한다.
- 감정은 가격 제안 횟수를 차감하지 않는다.
- 같은 고객 물건을 두 번 감정할 수 없다.
- 감정 후에도 가격 제안 또는 거래 포기를 선택할 수 있다.
- STAGE 1부터 감정 UI를 표시한다.

### 4. 감정 결과와 시간 정지

- 감정 결과는 `진품` 또는 `가품` 팝업으로 즉시 표시한다.
- 결과 팝업이 열려 있는 동안 GameState 영업시간과 CustomerQueue 대기시간을 정지한다.
- 팝업이 열린 동안 가격 입력, 제안, 거래 포기, 재고/다른 팝업 조작을 막는다.
- `확인`을 누르면 거래 화면으로 돌아가고 시간이 다시 흐른다.
- 감정 여부를 고민하는 시간과 버튼을 누르기 전 시간은 계속 흐른다.
- 사용자 승인 시각 변경(2026-08-23): 감정 결과 팝업은 기존의 코드 사각형을 제거하고,
  검정 목재·얇은 낡은 황동 테두리·절제된 모서리 장식을 사용한 단순한 결과 카드로 표시한다.
  `진품`·`가품`은 별도의 명패나 컨테이너로 감싸지 않고 목재 배경 위에 런타임 텍스트로 직접
  표시하며, 확인 버튼은 문구가 없는 분리 이미지 위에 동적 텍스트로 구성한다. 장식은 결과 판독을
  방해하지 않는 범위로 제한한다.

### 5. HUD와 결과 유지

- 영업 HUD에 보유 감정권 수량을 표시한다.
- 현재 고객을 감정한 뒤에는 거래가 끝날 때까지 거래 UI에 진품·가품 결과를 표시한다.
- 구매가 성사되면 기존 PRD 5-1처럼 재고에 결과를 저장한다.
- 거래를 거절하거나 결렬해도 사용한 감정권은 돌아오지 않는다.

## 범위 밖

- 시세 확인권, 장사 시간 증가, 방어 아이템
- 여러 종류를 파는 완성형 아이템 상점
- 감정 스킬과 영구 장비
- 감정 애니메이션·사운드·신규 이미지
- 감정 후 손님에게 가품임을 알리는 대사나 가격 변경
- 손님 유형, 신뢰도, 공격

## 시스템 책임

- **SpecialItemInventory**: 감정권 보유·구매·소비 수량.
- **ItemShop 규칙**: STAGE/DAY별 상점 노출, 가격, 방문당 구매 제한.
- **TradeSession 또는 AppraisalSession**: 현재 고객의 감정 여부와 공개 결과.
- **DailyLedger**: 아이템 구매 비용 기록.
- **GameState / DayScene**: 결과 팝업 동안 시간 정지와 화면 전환 조정.

## 완료 조건

1. 새 게임은 감정권 1개로 시작하며 STAGE 1 첫 영업 종료 상점부터 추가 구매할 수 있다.
2. 모든 DAY 영업 종료 뒤 상점이 정확히 한 번 열린다.
3. 방문당 3,000원짜리 감정권을 최대 1개 구매할 수 있다.
4. 구매 시 현금·감정권·DailyLedger가 정확히 한 번 변경된다.
5. 현금 부족 시 상태 변경 없이 구매를 거부한다.
6. 상점 종료 후 일일 명세서에 아이템 구매 비용이 표시된다.
7. DAY 3에는 보따리 상인 종료 후 상점이 열리고, 상점 종료 후 STAGE 정산으로 이어진다.
8. 모든 STAGE 고객의 첫 가격 제안 전에만 감정권을 사용할 수 있다.
9. 감정권 사용 시 수량은 즉시 1개 감소하고 흥정 횟수는 유지된다.
10. 같은 고객에게 중복 감정할 수 없고 거래 종료 뒤에도 감정권은 반환되지 않는다.
11. 결과 팝업 동안 영업시간·고객 큐·거래 입력이 정지된다.
12. 결과 확인 후 시간과 거래가 정상 재개된다.
13. 감정 결과는 현재 거래에 표시되고 구매 시 재고 결과와 일치한다.
14. DAY/STAGE 전환 시 미사용 감정권이 유지된다.
15. 기존 전체 테스트와 `npm run typecheck`, `npm run build`, `npm test`가 통과한다.

## 승인 시 확정되는 사항

1. 감정권은 모든 DAY 종료 상점에서 3,000원에 한 개씩 구매한다.
2. 상점은 일일 명세서 전에 열어 구매 비용을 같은 DAY에 기록한다.
3. 감정은 첫 가격 제안 전에만 가능하다.
4. 결과 팝업을 닫을 때까지 영업시간과 모든 거래 입력을 정지한다.
