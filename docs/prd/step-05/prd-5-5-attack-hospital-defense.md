# PRD 5-5 — 공격·병원비·방어 아이템

> 출처: Notion `통합 기획서` §27~29·§31~33·§42, `거래·흥정 규칙` §6·§12·§16~18, `아이템·월세·보따리 상인` §1~2
> 작성일: 2026-08-19 (Notion 기준 2026-08-18T14:47Z)

## 목표

지나치게 낮은 제안에 공격 위험을 추가하고, 병원비 손실과 소모형 방어 아이템으로 위험 관리 선택을 만든다.
STAGE 1에도 위험을 두되 STAGE 2보다 약하게 한다(사용자 승인 변경 2026-08-26).

### 사용자 승인 변경 — 전용 아이템 아이콘

- 방어 부적은 기존 매입품 반지 그림을 재사용하지 않고, 붉은 봉인과 보호 문양이 있는
  낡은 종이 부적 전용 아이콘을 사용한다.
- 같은 전용 아이콘을 아이템 상점과 영업 중 아이템 창에서 공통으로 사용한다.

## 범위

- 공격은 최저 수용 가격 미만 제안 뒤에만 판정한다.
- 사용자 승인 변경(2026-08-26): STAGE 1에서도 공격이 발생한다. 원래는 STAGE 2부터만
  판정했으나, STAGE 1에도 위험을 두어 방어 부적과 흥정 절제에 의미를 주기로 했다.
  대신 STAGE별 배율(`attackChanceMultiplierByStage`)로 세기를 나눈다.
  STAGE 1은 계산된 확률의 40%, STAGE 2는 100%다(현재 테스트값).
  배율을 0으로 두면 그 STAGE에서는 공격이 발생하지 않는다.
- 제안 비율, 라운드, 신뢰도, 손님 유형을 config 기반 확률에 반영한다. 공격 성향으로 설정된
  손님만 공격 판정 대상이며 일반·정직형 손님은 화를 내거나 결렬될 수 있어도 공격하지 않는다.
- 사용자 승인 변경(2026-08-25): 공격 성향 손님이 실제로 생성되도록 손님 유형을 이름별 표로 고정한다.
  이전에는 이름 문자 코드 합의 나머지로 유형을 정해 13개 이름이 모두 정직·일반으로 떨어졌고,
  공격 성향 손님이 한 명도 없어 STAGE 2 공격 확률이 실제로 0%였다.
  배정: 정직 4(토끼·수달·두루미·부엉이) / 일반 4(흰고양이·독수리·염소·너구리) /
  의심 3(뱀·검은고양이·사자) / 사기 2(늑대·여우). 배정은 현재 테스트값이다.
- 공격 발생 시 거래 즉시 종료, 결과 안내 동안 시간 정지, 현재 테스트 병원비 3,000원 차감 및 장부 기록.
- 현금이 병원비보다 적으면 0원까지만 차감하고 실제 차감액을 기록한다.
- 방어 아이템은 종료 상점에서 현재 테스트값 3,000원, 방문당 1개 구매한다.
- STAGE 1부터 종료 상점에서 구매할 수 있다.
- 모든 STAGE의 영업 중 아이템 창의 방어 아이템을 사용하면 즉시 1개 소비하고, 이후 발생하는
  공격 1회를 막는다. 방어 성공 뒤 효과는 해제되고 해당 거래는 병원비 없이 종료되며 손님은 퇴장한다.
- 방어에 성공하면 재고 공간 부족 거래 불가 팝업과 같은 결과 프레임으로 `방어 성공` 안내를 표시한다.
- 방어 효과는 현재 DAY 안에서만 유지하며, 공격을 막지 않고 DAY가 끝나면 소멸한다.
- 명세서에 병원비를 별도 표시한다.

## 완료 조건

1. STAGE 1·2 모두 공격이 발생하고, 같은 조건에서 STAGE 1 확률이 STAGE 2보다 낮다.
2. 공격 확률이 config 값(STAGE 배율·반응·라운드·신뢰도·손님 유형)과 입력 상태를 반영한다.
3. 공격 시 거래 종료·병원비·장부가 정확히 한 번 처리된다.
4. 방어 아이템은 STAGE 1부터 구매·활성화할 수 있고, 활성화할 때 한 개 소비해 다음 공격 1회와
   병원비를 막은 뒤 해제된다.
5. 공격 결과 안내 중 영업시간과 고객 대기가 정지한다.
6. 방어 성공 시 결과 프레임과 확인 버튼이 표시되고, 확인 후 병원비 없이 손님이 퇴장한다.
7. DAY 종료 후에는 남은 방어 효과가 다음 DAY로 이월되지 않는다.

## 범위 밖

- 공격 애니메이션·사운드·캐릭터 아트
- 체력, 사망, 공격으로 인한 즉시 GAME OVER
